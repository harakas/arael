# BAL datasets

Vendored problems from the Bundle Adjustment in the Large collection
(grail.cs.washington.edu/projects/bal), the standard bundle-adjustment
solver benchmark; the data has circulated freely across solver
repositories since 2010.

- `problem-49-7776-pre.txt` -- Ladybug sequence, 49 cameras, 7776
  points, 31843 observations.
  Cite: S. Agarwal, N. Snavely, S. M. Seitz, R. Szeliski, "Bundle
  Adjustment in the Large", ECCV 2010.
  This copy: grail.cs.washington.edu/projects/bal/data/ladybug/
  problem-49-7776-pre.txt.bz2 (decompressed).

`../fetch_datasets.sh` re-downloads from the original source.
